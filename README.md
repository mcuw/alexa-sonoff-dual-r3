# Alexa SonOff Dual R3 project

## Description

This is a project to use a Sonoff R3 with Alexa. Only for professional electric experts because handling with high voltage can be quite dangerous. No warranty! Use the project at your own risk..

## Features 

- Uses Platformio
- Example code

## Requirements

- SonOff Dual R3
- Alexa

## Get Started

1. Disconnect your SonOff from high power electric
2. Connect USB to serial port adapter to the GPIO pins
3. Hold the boot button and connect USB to your computer
4. Now, you are ready to flash your ESP32 on the SonOff R3
